# 模拟城市 1.12.2 新手教程

> 适用版本：**1.0.9 Beta13**（Minecraft 1.12.2 / Forge 14.23.5.2860）
> 游戏内随时按 `V` 打开市长手册；本文是同一套流程的完整文字版，额外补上了安装、经济循环和排错。

你是一片空地的市长。目标不是亲手盖每一栋房子，而是**放建筑箱、雇 NPC、等建筑完工、收租，再用租金扩建**。第一次玩建议全程使用「创造模式」，先跑通一遍流程，再开正常模式。

## 1. 安装与启动

### 使用 PCL 完整版

1. 从 [Releases](https://github.com/salt-fishes/simulated-city/releases) 下载 `Simulated-City-1.12.2-1.0.9-beta13-PCL.zip`；
2. 解压到任意目录。**不要在压缩包里直接运行**；
3. 双击 `启动器.bat` 打开 PCL2；
4. 确认版本列表选中 `Simulated-Beta13-Pack`，点击「启动游戏」。

游戏本体、Forge、运行库、Java 8 和模组都已经打包好，不需要另外下载。

备用启动方式：直接双击 `启动游戏.bat`，不经过 PCL，离线用户名固定为 `Player`。适合启动器打不开时使用。

### 光影（可选）

进入游戏后打开 `选项 → 视频设置 → 光影`，选择 `Sunflawer 0.4.1 Lightshaft Update`。默认没有启用，低配设备建议先关着。

### 启动排错

| 现象 | 处理 |
| --- | --- |
| PCL 没有自动选中版本 | 在版本列表里手动选 `Simulated-Beta13-Pack` |
| 版本列表是空的 | 点「添加游戏文件夹」，选择解压目录下的 `.minecraft` |
| PCL 提示 Java 有问题 | 在 `设置 → Java` 选择 `.minecraft\versions\Simulated-Beta13-Pack\runtime\jre-legacy\bin\java.exe` |
| 想换存档位置 | 存档放在 `.minecraft\versions\Simulated-Beta13-Pack\saves\` |
| 整个文件夹能搬吗 | 可以整体移动，但不要单独移动 `.minecraft` 或启动器文件 |

首次启动会在 `.minecraft\versions\Simulated-Beta13-Pack` 下生成 `logs`、`saves` 等目录，属于正常现象。

## 2. 常用操作

| 操作 | 作用 |
| --- | --- |
| 按 `V` | 随时打开市长手册，共 18 页 |
| 右键「模拟城市启动卷轴」 | 第一次打开任命书；之后直接进入模式选择，可随时改模式 |
| `/simmode` | 卷轴丢了时重新打开模式界面 |
| `/credits <金额>` | 调整城市资金，测试用（需要作弊 / 管理员权限） |

启动卷轴**不会消耗**，接受任命后仍然留在背包里。HUD 左上角提示「模拟城市未启动」时，就是城市还没启动；如果已经任命过，右键卷轴或建筑箱只会进入模式选择，**不会要求重新接受任命**。

## 3. 接受任命

1. 第一次右键「模拟城市启动卷轴」；
2. 点击「接受任命」；
3. 选择游戏模式；
4. 第一次确认后获得 **建筑箱 ×1、标记棒 ×3**。

已经任命过的玩家不需要重复第 1–2 步：右键卷轴或建筑箱会直接进入模式选择页。

### 选哪个模式

| 模式 | 特点 | 适合 |
| --- | --- | --- |
| **创造模式** ★ | 不消耗材料，也不扣建造费 | 第一次玩，先熟悉流程 |
| 正常模式 | 需要自己收集材料，初始资金 10，靠租金发展 | 熟悉之后正式开城 |
| 不启动 | 关闭本世界的模拟城市，之后可再打开 | 只想先看看地图 |

模式可以随时右键卷轴或用 `/simmode` 修改，不用重开世界，也**不需要再次接受任命**。第一次接受后会获得建筑箱 ×1、标记棒 ×3；之后切换模式不会重复发放，工具丢了可以用 `/simmode` 或重新制作。

## 4. 第一栋建筑

### 4.1 放下建筑箱

建筑箱的合成配方（在工作台里按 3×3 摆放；游戏内手册第 7–8 页有图标版）：

| 左 | 中 | 右 |
|:---:|:---:|:---:|
| 木板 | 木板 | 木板 |
| 圆石 | 工作台 | 圆石 |
| 圆石 | 圆石 | 圆石 |

- 木板：任意木种，3 个；
- 工作台：1 个，放正中间；
- 圆石：5 个；
- 合成结果：建筑箱 ×1。

> 游戏内按 `V` 打开手册，第 7–8 页「合成配方速查」直接画出了建筑箱、耕种箱、采矿箱和标记棒的 3×3 摆放，鼠标悬停还能看物品名。

找一块**平整、开阔**的空地，放下建筑箱，并给建筑留出足够空间。第一栋推荐选 **5×6×5 左右的小住宅**，周围再留几格放箱子。

放下后右键建筑箱打开界面。

### 4.2 先雇建筑工

这是新手最容易卡住的一步。

建筑工要从**失业 NPC**里雇。雇佣列表不会按距离过滤，会列出全城所有失业成年人，所以列表里有名字不代表一定雇得上。

实操建议：

- 打开建筑箱前，先看看附近有没有失业 NPC；
- 失业 NPC 的资料里职业显示「失业的」，未成年不能雇；
- 列表里只有远处的名字时，先走近那个 NPC，再打开建筑箱；
- 新居民不是随时出现；没有合适的人就先等等，或先安置现有居民。

在建筑箱主页点「雇佣建筑工」，从失业列表里选一个 NPC，点「好」。

雇上后 NPC 会自己移动到工地；如果只是界面显示已雇佣、人却没来，关掉建筑箱再打开确认一下。

### 4.3 选择建筑

回到主页点「选择建筑」。上方是「全部」页签加六个分类：

`全部` / `住宅` / `商业` / `工业` / `其他` / `特殊` / `装饰`

列表支持：

- 左侧搜索框按名字查找；
- 点表头「名称 / 规格 / 费用 / 来源」排序，再点一次反向；
- 「占地」筛选小 / 中 / 大；
- 「预算」只看当前资金够不够；
- 滚轮或底部 `< >` 翻页；
- 点整行进入详情，**不会直接开建**。

第一次选 5×6×5 左右的小住宅即可。详情页点「预览」可以先看位置和朝向。

### 4.4 正常模式：把材料放进箱子

在建筑箱**周围 5 格内**放箱子，把材料装进去。建筑工会自己过去取。

需要材料的主要是这些基础方块：

`木板` `原木` `圆石` `石头` `玻璃` `羊毛` `砖块` `石砖` `泥土` `栅栏` `墙`

几个省事规则：

- 木板、原木、木栅栏、羊毛可以交**任意木种或颜色**，但建筑外观仍按蓝图放置；
- 门、楼梯、半砖、火把等由建筑工直接放置，不需要你提供；
- 一个箱子不够就放双箱，但不要放得太远；
- 放好后点「需求」核对清单，缺什么补什么。

### 4.5 开工

确认建筑工已雇、材料已到位，点「建造它」。建筑工会自己取材料施工，完工后原地生成**控制箱**。

第一栋房子的检查清单：

- [ ] 建筑箱放在平整空地，周围留了空间
- [ ] 已雇佣建筑工（不是「待雇佣」状态）
- [ ] 已选中一套小住宅蓝图
- [ ] 正常模式下，箱子在建筑箱 5 格内
- [ ] 点过「需求」确认材料齐全
- [ ] 城市资金高于 0.02

## 5. 租金与资金

HUD 左上角显示 **天数、星期、季节、人口、资金**。季节来自 Serene Seasons；没有安装四季模组时只显示前面几项。

经济循环很简单：

```text
建住宅 → NPC 入住 → 每天收租 → 用租金建更多住宅 / 商店 → 人口和岗位增加
```

| 规则 | 说明 |
| --- | --- |
| 初始资金 | 正常模式 10 |
| 租金来源 | 住宅有人入住、商业 / 工业建筑有员工 |
| 租金高低 | 按蓝图体积（长 × 宽 × 高）计算 |
| 结算方式 | 每天自动结算，聊天栏提示；右键控制箱看明细 |
| 建造费用 | 正常模式约每格 0.02；创造模式不扣 |
| 停工线 | 资金低于 0.02，建筑师和工人会停工 |

### 银行

右键银行里的行长打开 ATM：

- 卖钻石、绿宝石、红石、萤石、金、铁；
- 买商品；
- 价格会随库存变化。

建议手里留一点余钱，不要把所有资金都砸进新工地。工地一多，工资和建造费会同时吃钱。

## 6. 控制箱

建筑完工后会生成控制箱，右键打开：

| 建筑类型 | 能做什么 |
| --- | --- |
| 住宅 | 查看住户和租金；没人入住就没有租金 |
| 商业 / 工业 | 查看员工和岗位，解雇或补雇 |
| 任意建筑 | 「拆除」会移除建筑；先确认住户 / 员工已经搬走 |

租金每天自动到账。资金变化看 HUD，明细看控制箱。

## 7. 农业

### 7.1 圈地

在田里放 **3 根标记棒**：

- 左前
- 右前
- 左后

三根棒围出的矩形就是农田范围。

标记棒不够可以合成（产出 1 根）：

| 左 | 中 | 右 |
|:---:|:---:|:---:|
| 空 | 黄色染料 | 空 |
| 空 | 木棍 | 空 |
| 空 | 木棍 | 空 |

### 7.2 放耕种箱

耕种箱的合成配方（在工作台里按 3×3 摆放）：

| 左 | 中 | 右 |
|:---:|:---:|:---:|
| 木板 | 木板 | 木板 |
| 圆石 | 铁锄 | 圆石 |
| 圆石 | 圆石 | 圆石 |

- 木板任意木种，3 个；
- 铁锄 1 把，放正中间；
- 圆石 5 个；
- 合成结果：耕种箱 ×1。

在区域内放下耕种箱，右键打开。

### 7.3 设置并雇人

- 在 GUI 里选作物类型、朝向、大小；
- 默认 9×9，可调；区域太小会提示；
- 点「雇佣农民」，选一个 NPC；
- 在附近 5 格内的箱子里放种子；
- 收获也会进箱子。

农民自带铁锄，会锄地、放水、种植和收割。城市资金需要高于 0.02。

## 8. 采矿

和农业同样的流程：

1. 放 3 根标记棒（左前、右前、左后）圈出矿区；
2. 放下采矿箱（配方见下）；
3. 右键打开，调朝向 / 大小，默认 6×6；
4. 点「雇佣矿工」；
5. 在采矿箱周围 5 格内放箱子，矿工会把挖到的方块放进去。

采矿箱的合成配方（在工作台里按 3×3 摆放）：

| 左 | 中 | 右 |
|:---:|:---:|:---:|
| 木板 | 木板 | 木板 |
| 圆石 | 铁镐 | 圆石 |
| 圆石 | 圆石 | 圆石 |

- 木板任意木种，3 个；
- 铁镐 1 把，放正中间；
- 圆石 5 个；
- 合成结果：采矿箱 ×1。

注意：

- 只圈石头和矿石，**不要把房子、箱子圈进去**；
- 资金需高于 0.02；
- 矿工只在区域内挖掘。

## 9. 其他职业

| 职业 | 需要准备什么 |
| --- | --- |
| 伐木工 | 附近有树和箱子；会砍树并把原木放进箱子 |
| 养殖（牛 / 猪 / 鸡 / 羊） | 围栏、动物和箱子；没有动物不会产出 |
| 渔夫 | 水域 |
| 牧羊人 | 羊 |
| 士兵 | 军营；会巡逻并攻击敌人 |

大多数职业附近都要箱子。矿工、农民等还需要城市资金高于 0.02。岗位越多，工资支出越大，先保证资金为正，再增加岗位。

## 10. 商店与物流

### 10.1 开店

商店、银行、花店、诊所、军营都要**先建对应建筑**，再右键控制箱雇员工。

杂货铺、面包店、肉铺、餐厅会自动向物流中心下单，不需要你手动搬货。

### 10.2 物流中心

```text
物流中心 = 仓库建筑 + 快递员
```

- 没有快递员，店铺会显示「等待派送」；
- 快递员会去农场、矿场、生产点取货，再送到下单店铺附近的箱子；
- 仓库控制箱有「物流」页：可开关自动派送、逐物品派送；
- 每件货物收少量配送费。

### 10.3 银行

右键银行行长打开 ATM：卖矿物、买商品，价格随库存变化。

如果 ATM 提示「抢银行」，检查银行附近是不是放了钻石、绿宝石或金块。

## 11. NPC 与人口

- NPC 需要住宅；成年 NPC 无家时会阻止新居民生成；
- 他们白天上班、傍晚社交、夜里回家睡觉，士兵例外；
- 人口增长受空住宅和人口上限限制；
- NPC 会年龄增长、结婚、生育，孩子需要时间长大；
- 右键 NPC 查看资料 / 关系；右键控制箱查看住户和员工；
- 资金低于 0.02 时工人会停工。

发展顺序建议：**先住宅，再岗位，再商店**。住宅不够，新居民不会来；岗位不够，居民没有收入；商店和物流是后期的事。

## 12. 第一天路线

- [ ] 右键卷轴 → 接受任命 → 选**创造模式**（只有第一次需要；之后右键直接进模式页）
- [ ] 找平地 → 放建筑箱 → 右键打开
- [ ] 先雇建筑工（从失业列表里选一个 NPC）
- [ ] 选一套 5×6×5 左右的小住宅 → 预览 → 建造
- [ ] 完工后右键控制箱，等 NPC 入住
- [ ] 用租金再建 1–2 栋住宅，把人口拉起来
- [ ] 放 3 根标记棒 + 耕种箱，雇农民，箱子放种子
- [ ] 资金稳定后再考虑商店、仓库和快递员
- [ ] 卡住就按 `V` 看手册 FAQ

## 13. 常见问题

| 问题 | 原因 / 解决 |
| --- | --- |
| 「选择建筑」是灰的 | 还没雇建筑工。先在建筑箱主页雇人 |
| 已经任命过，打开建筑箱又要任命 | 当前版本已修复：世界加载时立即读取模式，任命后写入存档；城市未启动时只会打开模式页，不会再要求接受任命 |
| 打开建筑箱提示城市未启动 | 城市被切到了「不启动」；在模式页选创造或正常模式即可，不需要重新接受任命 |
| 没有可雇的 NPC | 列表是全城的，列表里有名字不代表一定雇得上；走近 NPC 再开箱试一次 |
| 建筑师不动 | 资金低于 0.02，或材料没放进建筑箱周围 5 格内的箱子 |
| 材料交不进去 | 箱子太远；或者这种材料由建筑工直接放置，不需要交 |
| 建筑列表是空的 | 蓝图还在加载，等一会儿，返回再重进建筑箱 |
| 不收租 | 住宅没人住，或商业 / 工业没有员工；右键控制箱确认 |
| 卷轴丢了 | 输入 `/simmode` 重新打开模式界面 |
| 想测试资金 | 输入 `/credits <金额>`（需要作弊 / 管理员权限） |
| 专家 / 硬核模式进不去 | 当前版本未开放，正常 / 创造模式不受影响 |
| 门、床、楼梯放歪了 | Beta13 已知蓝图问题，见第 14 节 |
| 帧数太低 | 关闭光影；`选项 → 视频设置 → 光影` 里选「无」 |

## 14. 已知问题

Beta13 仍有以下限制：

- 蓝图中的**门、床、告示牌、楼梯、火把、画 / 物品展示框**放置可能出错：
  - 门 / 床可能偏移或缺少半块；
  - 告示牌文字会丢失；
  - 楼梯转角可能错误；
  - 画 / 展示框可能因墙体替换而掉落。
- **专家 / 硬核模式**没有恢复入口：GUI 没有按钮，服务端只接受 `0/1/999`，也没有「全部材料」规则。
- 启动日志可能出现少量旧蓝图或第三方模组提示；如果出现 `addBuildingBlueprint` 空指针，请确认使用的是 Beta13 或更新版本。

详细报告见 [blueprint-special-blocks.md](blueprint-special-blocks.md)。
